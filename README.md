# Projeto-solidario
O Ponte Solidária é uma plataforma web desenvolvida com o propósito de facilitar a organização, o gerenciamento e o acompanhamento de doações, promovendo a conexão entre pessoas que desejam ajudar e instituições ou comunidades que precisam de apoio. O projeto busca utilizar a tecnologia como ferramenta de transformação social, tornando o processo de doação mais acessível, organizado e eficiente. A plataforma conta com uma interface administrativa estruturada em diferentes telas, proporcionando uma navegação intuitiva e facilitando o acesso às funcionalidades do sistema. Desenvolvido com HTML5, CSS3 e JavaScript, o projeto também tem como foco a aplicação de conceitos de desenvolvimento front-end, organização de interfaces e experiência do usuário (UX/UI), unindo tecnologia, praticidade e solidariedade em uma única solução.
